1. Overzicht

D-OmniTwin ("The Omni Twin") is een digitale spiegel van de fysieke leefomgeving. De applicatie combineert geografische datavisualisatie, een AI-gedreven chat-assistent en een beheerpaneel voor Noord-Nederland (Fryslân, Groningen, Drenthe). De kern is een interactieve kaart met een Kompas-visualisatie van 217 indicatoren verdeeld over 12 thema's, op buurtniveau.

3. Frontend — Browser Laag

Hoofdapplicatie (app.js)

  • Mapbox GL JS — Basiskaart rendering.
  • deck.gl — 3D/2D polygon overlay.
    • GeoJsonLayer voor 2D choropleth
    • PolygonLayer voor 3D extrusie
  • Multi-gebied selectie via Shift+Click / Ctrl+Click.
  • Dynamische legenda en floating selectie-badge.

D-Omni Kompas (kompas.js)

  • D3.js — Sunburst-diagram met hiërarchie.
  • Parallelle data fetch voor multi-gebied + gewogen gemiddelden.
  • Contextuele zoom naar thema-niveau.
  • _isSyncing guard tegen event loops.

AI Chat (chat.js)

  • Vanilla JS klasse, geen framework.
  • Glassmorphism styling, thema-aware.
  • Beheert state: isOpen, isLoading.
  • Koppelt kaartcontext (gebied_id, indicator_uuid) aan API.

Core (event-bus.js)

  • Globale pub/sub singleton.
  • Centraal event: INDICATOR_SELECTED.
  • Draggable windows functionaliteit.

5. AI & Zoeken

Semantisch Zoeken (Vector Search)

Gebruikersvraag → SentenceTransformer
→ pgvector cosine similarity
→ Top 10 relevante indicatoren
  • Model: all-MiniLM-L6-v2 (~28MB, lokaal)
  • Index: ivfflat (vector_cosine_ops)
  • Snelheid: 50–150ms per query

LLM Generatie (Ollama)

Context + Prompt → Ollama API
→ qwen3:30b
→ ≤80 woorden tekst
  • Latentie: 2–15s (afhankelijk van warm start)
  • Timeout: 120s
  • Lazy loading: Pas bij eerste verzoek geladen.

11. Development Setup

Vereisten

  • Python 3.12+
  • Node.js 18+ & npm 9+
  • PostgreSQL 14+ met PostGIS + pgvector
  • Ollama lokaal op localhost:11434

Starten

# Backend
source .venv/bin/activate && python run_dev.py
# Admin Panel (dev)
cd admin-panel && npm start
# Admin Panel (productie)
cd admin-panel && npm run build
