Documentatie & Demo

Gegevensstroom en Database Interacties

Dit document beschrijft de volledige technische flow van hoe de Sunburst/Kompas visualisatie in de applicatie tot stand komt, van frontend requests tot onderliggende SQL iteraties in de database. De doelgroep is data scientists en backend developers die de kompas logica of scoringmechanismen verder willen uitbreiden.

1. De Stroom: Frontend naar Database

A Initialisatie (Welke kompassen zijn er?)

  • Frontend: Roept in de achtergrond /api/kompas/configuraties aan.
  • Backend: Routeert naar KompasService.get_configuraties().
  • Database: Query op de view v_kompas_config_stats voor meta-informatie.

B Interactie (Klik op een wijk/buurt)

Dit is de zwaarste en meest cruciale bewerking in de flow.

B1. Gebied Verificatie: Snelle query naar gebieden.
B2. De Boomstructuur (v_kompas_hierarchie): Haalt de platte taxonomie op. (Titel → Thema → Onderdeel → Indicator).
B3. Waarden ophalen (Lateral Join): 
LEFT JOIN LATERAL (
    SELECT waarde, jaar FROM gebied_data
    WHERE indicator_uuid = i.uuid AND gebied_id = :gebied_id
    ORDER BY jaar DESC LIMIT 1
) gd ON true
B4. Kleuring / Thresholds: Procentuele klassen berekenen: 
PERCENTILE_CONT(ARRAY[0.125, 0.25, ..., 0.875]) 
WITHIN GROUP (ORDER BY waarde)

C Detailweergave & Historie

Klik op de buitenste ring (Indicator) laadt de trendlijn via /history/{gebied_id}/{indicator_uuid}.

3. De Sunburst Transformatie

D3.js vereist een geneste JSON-structuur. De backend zet de platte SQL-rijen om naar deze boomstructuur. Kijk naar de interactieve demo hiernaast: de ringen vertegenwoordigen deze nestings-levels.

kompas_service.py 
# Stap 1: Flat SQL rijen groeperen per niveau
titels = {}
for row in rows:
    if row.titel_id not in titels:
        titels[row.titel_id] = {
            "name": row.titel_naam,
            "type": "titel",
            "color": row.titel_kleur,
            "children": {}
        }
    
    # ... Geneste ifs voor Thema & Onderdeel ...
    
    # Zodra de buitenste ring (Indicator) is bereikt:
    if row.indicator_uuid:
        titels[row.titel_id]["children"]...append({
            "name": row.indicator_naam,
            "type": "indicator",
            "value": None, # Gevuld in Stap B3/B4
            "color": None   
        })

# Stap 2: Dicts -> Lists voor D3.js
root_children = convert_dicts_to_lists(titels) 
return { "name": "Root", "children": root_children }
